# Log Analyzer 
A Python project that reads log files, counts different logs, identifies error logs, and generates a simple report.

## Concepts Used
- File Handling
- Functions
- Lists
- Conditional statements
- Loops
  
## Dataset
The project currently uses a manually created sample log file to simulate real-world application logs. This allows testing of log parsing, categorization, and report generation features.

Future improvements will include integrating larger real-world log datasets for more advanced analysis.

## Features
- Counts INFO, WARNING and ERROR logs.
- Extracts error message.
- Generates a report file.
