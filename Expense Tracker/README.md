# Expense Tracker 
## Overview
I made this project to practice Python by creating something that I could actually use.
It is a simple command-line expense tracker where users can add, view, search, and delete there expenses. It also provides a monthly summary and visualizes spending using charts.

This is Version 1 of the project. My goal was to keep the code simple and readable. I have intentionally not added comments this time because i wanted the code to be understandable on its own and based on the python concepts I have learned so far.

## Features 
- Add new expenses
- View all expenses
- Delete expenses
- Search expenses by category and note
- Monthly spending summary
- Category-wise Bar Chart
- Category-wise Pie Chart

## Tools used
- Python
- Matplotlib
- VS Code
